# Our Budget

다혜와 동구가 함께 쓰는, 실시간으로 동기화되는 우리 집 가계부 · 자산관리 웹앱.

## 프로젝트 목적

이 프로젝트는 데모가 아니라 다혜·동구 부부가 실제로 매달 사용하는 가계부다. 지출 내역과 고정지출, 저축, 자산 현황을 한곳에서 관리하고, 두 사람이 각자의 기기에서 열어도 같은 데이터를 실시간으로 보고 수정할 수 있게 하는 것이 목표다.

## 주요 기능

**월 사용 내역**
- 거래 내역 추가 · 수정 · 삭제 (날짜 / 대분류 / 중분류 / 소분류(메모) / 금액 / 다혜·동구·공동 구분)
- 표 하단 빠른 입력 줄, 상단 "+" 버튼을 통한 모달 입력 두 가지 방식 지원
- 카테고리 선택은 색상이 있는 픽커로 선택하거나 직접 입력 가능
- 검색(날짜·분류·내용·구분 통합 검색)
- "필터로 합계 계산" 모드: 구분/카테고리/키워드 조건에 맞는 항목만 체크해 원하는 대로 합계를 다시 계산
- 엑셀/CSV 일괄 가져오기: 파일 첨부 또는 셀 붙여넣기 → 미리보기 화면에서 행별로 수정·삭제 후 확정
- 조회 월 선택(월별 보기 / 전체 보기), 가계부 보기 필터(전체 / 다혜 / 동구 / 공동)
- 카테고리별 합계, 다혜·동구·공동별 합계를 펼쳐서 상세 내역 확인
- 고정지출 목록 (추가/수정/삭제, 결제일 기준 정렬), 저축·투자 목록 (추가/수정/삭제)
- 수입 내역 관리, 이번 달 저축 현황(수입 대비 지출·저축 비율) 카드

**자산 현황**
- 자산 추가 · 수정 · 삭제 (소유자, 금액, 현금화 가능 여부, 메모)
- 총자산 / 현금화 가능 / 현금화 불가 요약 카드
- 월말 스냅샷 저장 기능과 자산 추이 막대그래프
- 목표 자금 계획: 필요 자금 항목과 이미 마련된 돈(차감) 항목을 각각 관리하고, 목표 시점까지 남은 기간과 달성률·월 저축 필요액을 자동 계산

**공통**
- 방금 한 변경을 되돌리는 실행취소(undo) 기능 (Firestore 연결 여부와 무관하게 항상 동작)
- 날짜는 텍스트로 자유롭게 입력하거나(예: `7월 2일`, `7.2`, `0702`) 달력 아이콘으로 선택 가능

## 기술 스택

- Vanilla JavaScript, HTML, CSS — 프레임워크 없음, 빌드 과정 없음
- Firebase Firestore (compat SDK, CDN 로드)
- GitHub Pages 배포

## Firestore 실시간 동기화

쉽게 말하면, 다혜 폰과 동구 폰 중 한쪽에서 내용을 바꾸면 다른 쪽 화면에도 자동으로 반영된다. 모든 데이터는 Firestore의 `sharedBudgets/dahye-donggu` 문서 하나에 저장된다.

동작 방식: 변경이 생기면 로컬에서 먼저 되돌리기 기록을 남기고 `_rev`(변경 번호)를 하나 올린 뒤, 입력이 잠시 멈추면(약 0.25초 뒤) Firestore에 저장한다. 다른 기기의 변경은 `onSnapshot`으로 실시간 수신한다. 방금 내가 저장한 내용이 그대로 되돌아오는 경우(echo)는 실제 변경이 아니므로, `_rev`와 마지막으로 보낸 값(`lastLocalRev`)을 비교해서 구분한다(전체 내용을 문자열로 비교하는 방식은 사용하지 않는다).
